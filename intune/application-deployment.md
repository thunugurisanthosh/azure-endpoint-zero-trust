# Application Deployment

## Example Application
7-Zip or another approved test utility.

## Goal
Demonstrate centralized Windows application deployment through Intune.

## Procedure
1. Intune → Apps → All apps → Create.
2. Select the appropriate Windows application type.
3. Configure application information.
4. Assign to Corporate-Users.
5. Sync WIN11-01.
6. Check Company Portal.
7. Verify installation status in Intune.

## Validation
Expected:
Installed on WIN11-01
