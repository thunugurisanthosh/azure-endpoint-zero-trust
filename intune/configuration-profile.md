# Corporate Windows Configuration Profile

## Profile
Corporate-Windows-Configuration

## Platform

## Profile Type
Settings catalog

## Example Settings

- Microsoft Defender Antivirus enabled
- Password requirements enabled
- Screen lock enabled
- Security-related configuration enabled
